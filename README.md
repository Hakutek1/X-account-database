# 複垢データベース

fxTwitterからXアカウントのフォロワー数、フォロー数、投稿数、開設日を取得し、複数アカウントの比較・履歴確認・xlsx出力を行うダッシュボードです。

## ローカル設定

`.env.example` を `.env` にコピーします。アカウント取得はfxTwitterを利用します。

履歴はD1に匿名セッション単位で保存されます。ローカル開発ではWranglerのローカルD1が使われます。

## コマンド

```bash
npm run dev
npm run build
npm test
npm run lint
```

## 保存データ

保存対象はXユーザーID、ハンドル、表示名、フォロワー数、フォロー数、投稿数、取得日時です。アカウント開設日は画面に表示しますが、履歴およびxlsxには含めません。
